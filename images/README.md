# Photos

Put the siege photos here. Each file name must match the spreadsheet's **Image 1** (or **Image 2**) column exactly, including capitals, spaces and the ending (`.jpg` is not `.JPG`).

Keep each photo under about 1 MB (around 1200 pixels wide). Open `check.html` on the live site to see which named photos are still missing.

The ten photos already here were matched by eye from an earlier upload; their credits still need adding to the Caption columns.
