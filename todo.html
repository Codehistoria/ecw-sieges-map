Guides and tools

Editing the spreadsheet
  1. Download data/sieges.csv from GitHub (open the file, then the download button) and open it in Excel.
  2. Make the changes. Find a row quickly with Ctrl-F and its ID.
  3. Save with File › Save As › "CSV UTF-8 (Comma delimited)". Plain "CSV" turns apostrophes into ?.
  4. On GitHub, open the data folder, choose Add file › Upload files, drop in sieges.csv and click Commit changes.
  5. Wait a minute, then refresh this page: fixed items disappear.

Small changes (one cell) can also be made directly on GitHub: open the file and click the pencil icon. Keep the commas and quote marks exactly as they are.

Correcting who attacked, who defended and who prevailed
  • The three columns are MAP Attacker, MAP Defender and MAP Outcome. Each takes exactly Parliamentarians, Royalists or Scots.
  • MAP Outcome is the side that came out on top: the attackers if the place fell, the defenders if it held or was relieved.
  • The circle's colour on the map, the "prevailed" label and the tour ring all come from these columns, so one fix corrects all three.
Photo credits: what a caption needs
  • Every photo needs a credit in Caption Image 1 (or Caption Image 2 for the second photo). Creative Commons licences require one.
  • Find the photographer and licence where the photo came from: the Geograph, Wikimedia Commons or Flickr page shows both.
  • Follow the form already used in the spreadsheet. The builder below writes it for you.
Adding or renaming photos
  • The file name in the photos folder must match the spreadsheet's Image 1 or Image 2 exactly, including capitals and the ending (.jpg, .JPG…).
  • To upload: on GitHub open the images folder, Add file › Upload files, then Commit changes.
  • Keep photos under 1 MB: about 1,200 pixels wide is plenty.
  • If a name is nearly right, the checker's near-miss list says what differs.
  • A row can name a second photo in Image 2; the map uses it whenever Image 1's file is missing.
Marking a reviewed issue as dealt with
  • Open data/known-issues.csv on GitHub and click the pencil icon.
  • Change that row's last column (Status) from Needs checking to Resolved, or to Fixed in data/sieges.csv if you changed the spreadsheet. Note what you decided in "What was done".
  • If the data was right after all, set it to Resolved and say so: the item still drops off this list.
Checking a story's tags and tour notes
  • Open the story on the map (the links below do this) and choose Follow the story. Each stop shows the line from data/story-steps.csv saying why it's there.
  • To remove a siege from a story, delete the tag from that row's Tags column in the spreadsheet. To add one, add the tag (separate tags with a semicolon) and a line for it in data/story-steps.csv.
  • To reword a stop, edit its Note in data/story-steps.csv. To reword the story itself, edit its row in data/stories.csv.
